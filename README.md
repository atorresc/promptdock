# PromptDock

A local-first prompt manager for AI chats — ChatGPT, Claude, Gemini, Perplexity, Grok,
Mistral and DeepSeek.

Save a prompt once, then pull it up in two keystrokes inside whichever model you happen
to be using. No account, no server, no telemetry: every prompt lives in your browser's
local storage and can be exported to JSON at any time.

**Website:** https://atorresc.github.io/promptdock/
**Privacy policy:** https://atorresc.github.io/promptdock/privacy.html

## Features

- Command palette on `Ctrl+Shift+Space`, or type `//` in the message box
- Cross-platform library — one set of prompts across every supported model
- `{{Placeholders}}` filled in at insert time
- Import / export to JSON
- Requests a single permission: `storage`
